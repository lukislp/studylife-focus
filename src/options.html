Connection

Point this at your own self-hosted StudyLife instance. Just the base address - no path needed.

Blocking mode

Chosen while a focus session is running, based on the endpoint above (GET /api/timerstate). FocusGuard never reads what the session is for - only whether one is active.

Allowed sites

Just the domain, e.g. wikipedia.org - subdomains are covered automatically, no need to list each one.
